# baduk-guide

초급자를 위한 바둑 학습 가이드 웹앱 (가칭: 바둑 첫걸음)

바둑을 처음 배우는 사람이 짧은 설명과 직접 두어 보는 문제를 따라가다, 9줄 판에서 한 판을 끝까지 두고 스스로 집을 셀 수 있게 되는 것이 목표입니다.

## 지금 상태 (v0.1 뼈대)

- 기획서: [docs/기획서.md](docs/기획서.md)
- 결정이 필요한 항목: [docs/결정사항.md](docs/결정사항.md)
- 연습판: `index.html`을 브라우저로 열면 됩니다. 인터넷이 없어도 동작합니다.
  - 9줄, 13줄, 19줄 판
  - 따내기, 착수금지, 패 판정
  - 놓인 돌을 누르면 활로 표시, 단수 알림
  - 무르기, 한 수 쉬기, 두 번 연달아 쉬면 집 계산(임시)
  - 두던 판은 기기 안에 저장

## 폴더

```
index.html              합쳐진 결과물 (직접 고치지 않습니다)
build.mjs               src/ 를 index.html 한 파일로 합치는 스크립트
src/rules.mjs           규칙 엔진 (화면과 무관한 순수 함수)
src/app.js              연습판 화면과 입력
src/style.css           스타일
src/index.template.html 화면 틀
tests/                  규칙 엔진, 빌드 결과 테스트
docs/                   기획서, 결정사항
```

## 명령

```
npm test        # 테스트 (node --test)
npm run build   # index.html 다시 만들기
```

Node.js 20 이상이면 됩니다. 설치할 패키지는 없습니다.

## 규칙 기준

한국 바둑규칙(한국기원, 대한바둑협회)을 따릅니다. 집과 따낸 돌을 더해 많은 쪽이 이기고, 백에게 덤 6집 반을 줍니다.
3패, 장생 같은 드문 동형반복은 다루지 않습니다(단순 패만 처리).
