# baduk-guide

초급자를 위한 바둑 학습 웹앱 "바둑 첫걸음"

바둑을 처음 배우는 사람이 짧은 설명과 직접 두어 보는 문제를 따라가다, 9줄 판에서 한 판을 끝까지 두고 스스로 집을 셀 수 있게 되는 것이 목표입니다.

- 바로 열기: https://irun20000-eng.github.io/baduk-guide/
- 파일로 쓰기: `index.html` 하나만 내려받아 열어도 됩니다. 인터넷이 없어도 동작하고, 기록은 기기 안에만 저장됩니다.

## 들어 있는 것 (v1.1)

- 5단원 24차시: 돌과 친해지기(7), 꼭 알아야 할 규칙(4), 삶과 죽음(4), 돌 잡는 기술(6), 한 판 두기(3)
- 문제 유형: 한 수 문제, 수 세기, 고르기, 짚기, 돌 눌러 활로 보기, 둘 수 없는 자리에 두어 보기, 수순 따라 두기, 끝까지 몰아 잡기(상대가 알아서 받음). 힌트 2단계, 별 1~3개
- 단원 미션: 따내기 바둑, 집 세기, 사활 10문제, 기술 10문제, 첫 대국
- 9줄 대국: 쉬운 상대 돌돌이와, 또는 한 기기에서 둘이서. 끝나면 죽은 돌을 골라 집을 셉니다
- 연습판(9줄, 13줄, 19줄), 용어 사전
- 프로필 최대 5명, 프로필마다 진행도 저장
- v1.1: 돌 소리와 진동, 틀린 문제 다시 풀기, 키보드로 두기(화살표, Enter, P), 기록 내보내기·가져오기, 밝은 화면, 인터넷 없이 열기(주소로 한 번 연 뒤), 새로 생긴 것 안내

## 폴더

```
index.html              합쳐진 결과물 (직접 고치지 않습니다)
sw.js                   빌드가 만드는 서비스 워커 (직접 고치지 않습니다)
build.mjs               src/ 를 index.html 한 파일로 합치는 스크립트
src/rules.mjs           규칙 엔진 (화면과 무관한 순수 함수)
src/lesson-engine.mjs   판 그림 읽기, 문제 조건 계산(축·장문·사활 읽기 포함), 차시 자료 검산
src/lessons.mjs         차시 자료 묶음과 1단원
src/lessons/            2~5단원 자료, 판 뒤집기 도구
src/glossary.mjs        용어 사전 자료
src/ai.mjs              쉬운 상대 "돌돌이"
src/store.mjs           프로필과 진행도 저장, 복습 목록, 기록 파일 검사
src/settings.mjs        기기 설정(소리, 진동, 화면), 판 번호, 새로 생긴 것
src/sw.template.js      서비스 워커 원본 (빌드가 sw.js 로 만든다)
src/ui/sound.js         돌 소리와 진동 (WebAudio)
src/ui/board.js         바둑판 그리기
src/ui/app.js           화면
src/style.css           스타일
src/index.template.html 화면 틀
tests/                  규칙, 차시 자료 검산, 쉬운 상대, 저장, 용어 사전, 빌드 테스트
docs/                   기획서, 결정사항, 디자인
```

## 명령

```
npm test        # 테스트 (node --test)
npm run build   # index.html 과 sw.js 다시 만들기 (둘 다 커밋)
```

Node.js 20 이상이면 됩니다. 설치할 패키지는 없습니다.

## 차시를 고치거나 더할 때

`src/lessons.mjs`와 `src/lessons/`만 고치면 됩니다. 판은 글자 그림으로 적고, 정답 자리는 `*`로 표시합니다.
`npm test`가 모든 문제의 정답을 규칙 엔진으로 다시 계산해서 자료와 다르면 알려 줍니다.
고친 뒤 `npm run build`로 `index.html`을 다시 만들고 main에 올리면 배포 주소에 반영됩니다.

## 규칙 기준

한국 바둑규칙(한국기원, 대한바둑협회)을 따릅니다. 집과 따낸 돌을 더해 많은 쪽이 이기고, 백에게 덤 6집 반을 줍니다.
3패, 장생 같은 드문 동형반복은 다루지 않습니다(단순 패만 처리).
