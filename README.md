# baduk-guide

초급자를 위한 바둑 학습 가이드 웹앱 (가칭: 바둑 첫걸음)

바둑을 처음 배우는 사람이 짧은 설명과 직접 두어 보는 문제를 따라가다, 9줄 판에서 한 판을 끝까지 두고 스스로 집을 셀 수 있게 되는 것이 목표입니다.

## 지금 상태 (v0.2, 1단원)

`index.html`을 브라우저로 열면 됩니다. 인터넷이 없어도 동작하고, 기록은 기기 안에만 저장됩니다.

- 1단원 "돌과 친해지기" 7차시: 바둑판과 돌, 활로, 이어진 돌, 따내기, 단수, 달아나기와 잇기, 끊기
- 문제 유형: 한 수 문제, 수 세기, 고르기, 짚기, 돌 눌러 활로 보기. 힌트 2단계, 별 1~3개
- 1단원 미션 "따내기 바둑": 쉬운 상대 돌돌이와, 또는 한 기기에서 둘이서
- 프로필 최대 5명, 프로필마다 진행도 저장
- 연습판: 9줄, 13줄, 19줄. 따내기, 착수금지, 패 판정, 활로 표시, 단수 알림, 집 계산(임시)
- 2~5단원은 준비 중

문서
- 기획서: [docs/기획서.md](docs/기획서.md)
- 결정사항: [docs/결정사항.md](docs/결정사항.md)

## 폴더

```
index.html              합쳐진 결과물 (직접 고치지 않습니다)
build.mjs               src/ 를 index.html 한 파일로 합치는 스크립트
src/rules.mjs           규칙 엔진 (화면과 무관한 순수 함수)
src/lesson-engine.mjs   판 그림 읽기, 문제 조건 계산, 차시 자료 검산
src/lessons.mjs         차시 자료
src/ai.mjs              쉬운 상대 "돌돌이"
src/store.mjs           프로필과 진행도 저장
src/ui/board.js         바둑판 그리기
src/ui/app.js           화면 (홈, 차시, 따내기 바둑, 연습판, 프로필)
src/style.css           스타일
src/index.template.html 화면 틀
tests/                  규칙, 차시 자료 검산, 쉬운 상대, 저장, 빌드 테스트
docs/                   기획서, 결정사항
```

## 명령

```
npm test        # 테스트 (node --test)
npm run build   # index.html 다시 만들기
```

Node.js 20 이상이면 됩니다. 설치할 패키지는 없습니다.

## 차시를 고치거나 더할 때

`src/lessons.mjs`만 고치면 됩니다. 판은 글자 그림으로 적고(파일 머리말 참고), 정답 자리는 `*`로 표시합니다.
`npm test`가 모든 문제의 정답을 규칙 엔진으로 다시 계산해서 자료와 다르면 알려 줍니다.

## 규칙 기준

한국 바둑규칙(한국기원, 대한바둑협회)을 따릅니다. 집과 따낸 돌을 더해 많은 쪽이 이기고, 백에게 덤 6집 반을 줍니다.
3패, 장생 같은 드문 동형반복은 다루지 않습니다(단순 패만 처리).
